## Do these first — both are bleeding right now

### 1. M5 moved; SPARK has been on paid Claude for days

M5's DHCP lease moved **192.168.0.100 → 192.168.0.249**, and the plain router-DNS name
`M5` no longer resolves from the Pi at all. M5 is dual-homed (ethernet/wifi), so the
router binds the name to whichever lease was recorded last; mDNS is unaffected because
it is advertised per host.

Verified from the Pi on 2026-08-05:

```
getent hosts M5        → rc=2   (does not resolve)
getent hosts M5.local  → 192.168.0.249   5/5 tries, 18–33 ms
192.168.0.249:11434 → 200      192.168.0.100:11434 → dead
192.168.0.249:7862  → 200      192.168.0.100:7862  → dead
```

Consequences, both silent:

- `mind.py:313` hardcodes `http://M5:11434`, no `PX_OLLAMA_HOST` override in the Pi
  `.env`. **639 `falling back to claude` events in `px-mind.log`, 126 on 2026-08-05
  alone.** Every recent thought shows `backend: claude`. `ollama-m5` last served
  2026-08-03.
- `spark_config.py:59` hardcodes `ANNOUNCE_RELAY_URL = "http://192.168.0.100:7862"`.
  **No Nest cast since 2026-07-31.** The comment on that line predicted exactly this
  failure mode.

**Fix:** `PX_OLLAMA_HOST=http://M5.local:11434` in the Pi `.env`. The relay must stay
an IP (Nests cannot resolve mDNS) and needs a UDR7 reservation pinned to *both* of M5's
MACs — same pattern already used for the Pi's eth0/wlan0. Correct the now-inverted
comment at `mind.py:311-312`.

### 2. Two coordinate leaks into the reflection prompt

dumping it into the prompt at `mind.py:2697`. Two keys carry coordinates:

- **`findmyhub`** (`mind.py:2113`) — Obi's tracker. Live: `{"obi_chipolo": {"lat":

- **`ha_presence`** (`mind.py:858-863`) — per-person GPS. Live: `{"name": "Adrian",
  "state": "home", "lat": -43.13558, "lon": 147.11829, "gps_accuracy_m": 5.0}` —

The comment at `mind.py:2829-2831` asserts tracker locations are excluded. They are

**Fix now, do not wait for the spec.** Use an **allowlist** of keys to include, not a
denylist — a denylist that drops only `findmyhub` leaves the house address flowing, and
any future awareness key reopens the hole. Historical thoughts already written are
unaffected by the fix and were not audited.

   (`mind.py:2435`) never calls `claude_session.check_budget()`. The 8/day cap,
   cooldowns and `claude_sessions.jsonl` cannot see it. Combined with incident 1 that
   is an uncapped paid call every reflection interval.

   reference to it). 522 logged sessions — research, compose, blog, consolidate,
   evolve, self_debug — are entirely absent from `token_usage.json`. Spend telemetry
   measures the cheap path and ignores the expensive one.
3. **Consolidation's 2-attempt retry is dead code.** `memory.py:37`
   `MAX_ATTEMPTS_PER_DAY = 2` against `claude_session.py:78` `consolidate: 72000`
   (20h) with quota 1. First failure at 02:00 locks out until 22:00, outside the
   02:00–06:00 window. Found independently by codex and hermes.
4. **`explore` is unreachable.** `VALID_ACTIONS` (`mind.py:377`) has 27 entries; the
   prompt enum (`spark_config.py:358`) lists 26 — `explore` is missing. A full
   dispatch handler exists at `mind.py:3464-3514`. On a branch named
   `feat/intelligent-wander`, SPARK cannot choose to wander.
5. **Goals have never fired.** `state/intention-spark.json` does not exist on the Pi.
   Over the last 2000 thoughts: `set_goal` 0, `complete_goal` 0, `update_goal` 1.
6. **Action distribution is degenerate.** Last 2000 thoughts: `comment` 766, `wait`
   711 — 74% of SPARK's inner life. Then `introspect` 146, `remember` 105,
   `research` 85, `compose` 75, everything else in single digits. `announce` 0.
7. **Gates are applied after the LLM commits.** `CHARGING_GATED_ACTIONS`,
   `CALL_GATED_ACTIONS`, `NIGHT_ALLOWED_ACTIONS` are enforced in `expression()`
   (`mind.py:3320/3360/3370`), so a reflection can be spent on an action that was
   never legal. Build the action enum per tick instead.
8. **The 8/day cap is raceable** — checked before the run (`claude_session.py:297`),
   locked only on append (`:245`). Plausible; not reproduced.
9. **`px-blog` can eat 5 of 8 daily sessions** and is exempt from the global cooldown
   (`claude_session.py:87`, `:102`).
